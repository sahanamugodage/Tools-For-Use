Tools are listed by status. Live tools open directly in the browser. Planned tools are part of the roadmap and will ship as single HTML files following the same constraints.

01.1
JsonXplorer API Studio
Live
A REST API client and JSON exploration studio. Send requests, explore response trees, auto-repair escaped JSON, copy JSONPath, and export payloads. Powered by the Monaco editor.

Inspect, decode, and validate JSON Web Tokens. Visualize header and payload, check expiry, and inspect signatures without sending data anywhere.

Encode and decode Base64, compute hashes (MD5, SHA-1, SHA-256, SHA-512), and compare digests. Useful for inspecting opaque tokens and verifying integrity.
